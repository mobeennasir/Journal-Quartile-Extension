Journal Quartile

Phase 1 spike — DOI lookup only. No quartile / IF / category yet.

Paste a bare DOI, a doi.org link, or any publisher article URL — including nature.com and ScienceDirect links, whose DOI is read from the article page.

Already on the article page? “Check this page” reads the DOI from the open tab — no page fetch, so a publisher bot check can't block it.

Sources: Crossref first, OpenAlex fallback. Only data returned by the API is shown.
